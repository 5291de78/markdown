# A1

### 冯・诺依曼架构

将**指令存储器与数据存储器合并为同一个存储器**，共用一套地址总线 + 数据总线。指令、数据都存放在同一块内存，CPU 通过同一套总线分时读取指令或者数据。 特点：结构简单，成本低；取指令和读写数据**不能并行**，会发生总线冲突，存在冯诺依曼瓶颈。x86、ARM 经典单片机大多是冯诺依曼架构。

### 哈佛架构

**指令存储器、数据存储器物理分离**，拥有两套独立总线：指令总线、数据总线。CPU 可以同时从指令存储器读取指令，从数据存储器读写数据。 特点：可以并行访问指令与数据，吞吐更高；硬件结构更复杂。典型：DSP、部分 FPGA 内部处理器、STM32 等很多 MCU 内核。

### 核心区别

1. 存储：冯诺依曼**指令、数据共用内存**；哈佛**指令、数据存储器物理分开**
2. 总线：冯诺依曼一套总线；哈佛两套独立总线，支持并行访存
3. 性能：冯诺依曼分时访问，存在瓶颈；哈佛可同时取指 + 读写数据，速度更快
4. 复杂度：冯诺依曼简单；哈佛硬件成本更高

> 注：现代 CPU（x86/ARM）会使用**缓存分层**，L1 指令缓存、L1 数据缓存分开，属于**改进型哈佛缓存结构**，但主存仍然是统一内存，本质上依然是冯诺依曼架构

# A2

一个 CPU 时钟周期内，流水线会并行处理多条指令的不同阶段，单条指令完整生命周期分为 5 步：

1. **取指（Fetch）**：根据 PC/RIP 的值，从内存 / 指令缓存取出指令，送入指令寄存器；PC 自增，指向后续指令。
2. **译码（Decode）**：对取出的指令译码，识别指令类型、操作数，读取寄存器堆里需要的源操作数。
3. **执行（Execute）**：ALU 完成算术 / 逻辑运算；若是跳转指令，在此阶段计算目标地址并更新 RIP。
4. **访存（Memory）**：读写内存。load 指令从内存读数据，store 指令把数据写入内存；不需要内存访问的指令直接跳过。
5. **写回（Write-back）**：将运算结果写回通用寄存器堆，更新寄存器的值。

> 流水线并行：同一时钟周期，不同阶段同时处理多条指令，提升 CPU 吞吐。
