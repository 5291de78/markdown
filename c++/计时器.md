# 计时器

基础模板（统计一段代码耗时，单位：秒）

```c++
#include <iostream>
#include <chrono>
using namespace std;

int main()
{
    // 记录起始时间点
    auto start = chrono::high_resolution_clock::now();

    // ========== 要计时的代码 ==========
	/*code*/
    // =================================

    auto end = chrono::high_resolution_clock::now();

    // 计算时间差，转为double秒
    auto duration = chrono::duration<double>(end - start);
    cout << "耗时：" << duration.count() << " 秒\n";
    return 0;
}

```

换成毫秒 / 微秒（常用）

```c++
// 毫秒 ms
auto dur_ms = chrono::duration<double, milli>(end - start);
cout << dur_ms.count() << " ms\n";

// 微秒 us
auto dur_us = chrono::duration<double, micro>(end - start);
cout << dur_us.count() << " us\n";

```
