## 一、这种技巧的名字

- **SWAR**（**S**IMD **W**ithin **A** **R**egister，"寄存器内的 SIMD"）：把一台 256 位寄存器**看成很多个独立的小格子**，让一条普通整数指令（`&`、`+`、`>>`）同时作用于所有格子——用标量指令模拟出并行向量运算。这就是 Stage 0 标题里 "SWAR popcount" 的原文。
- 这个具体算法叫 **parallel bit count** / **sideways addition**，在数学上统计的东西叫**汉明重量**（Hamming weight，即 popcount，二进制中 1 的个数）。
- 这类技巧的总称是 **bit hacks / bit twiddling**（位运算黑魔法），经典书目是 Henry S. Warren 的 *Hacker's Delight*（《高效程序的奥秘》）第 5 章。

## 二、"树"是什么：归约树（reduction tree）

就是一个**分治的加法树**，每次把相邻两个格子合并成一个双倍宽的格子，格子数减半：

```
第0层: 256 个 1-bit 字段
第1层:  2-bit 相邻相加 → 128 个 2-bit 字段      ← 掩码 0x55..  + >>1
第2层:  4-bit 相邻相加 →  64 个 4-bit 字段      ← 掩码 0x33..  + >>2
第3层:  8-bit 相邻相加 →  32 个 8-bit 字段      ← 掩码 0x0F..  + >>4
        ……继续折半……
第8层:   1 个字段 = 答案
```

层数 = log₂(256) = 8。**最后那次乘法也是一棵树**：`A × 0x0001…0001 = A + (A<<16) + (A<<32) + …` 展开就是 16 路错位相加，一步乘指令把最后 4 层加法树压成了 1 层——这就是 `*` 值 3 步却顶 9 步的原因。

## 三、学习资料

**必读（英文原典）：**
- [Bit Twiddling Hacks — Sean Eron Anderson（斯坦福）](https://graphics.stanford.edu/~seander/bithacks.html#CountBitsSetParallel) — 位技巧百科全书，看 "Counting bits set, in parallel" 一节，我们的算法就是它的 256 位版；[GitHub 上的 Python 版整理](https://github.com/ianbrayoni/bithacks) 可直接跑
- [A Hybrid Implementation of Hamming Weight（UPC 论文 PDF）](https://hpc.ac.upc.edu/PDFs/dir19/file004398.pdf) — 明确写出 SWAR popcount 是 "parallel reduction in ⌈log₂⌉ levels"，树结构的权威表述

**中文（从易到难）：**
1. [经典算法学习——计算汉明权重 SWAR（博客园）](https://www.cnblogs.com/Albert-lihai/p/16650973.html) — 最短上手
2. [variable-precision SWAR 算法"计算汉明重量"（CSDN）](https://blog.csdn.net/qq_34930488/article/details/88311113) — 讲乘法收尾和移位窗口，正是你这道题的关键
3. [汉明重量算法深度解析（稀土掘金）](https://juejin.cn/post/7571379549370236979) — 对比 Kernighan 逐位消 1 和分治两种思路

**隐藏教材**：`java.lang.Integer.bitCount()` 的 JDK 源码、CPython `int.bit_count()` 的 C 实现，全是这个算法。

## 四、建议的学习顺序（半天能走完）

1. **建立"格子"视角**：拿 8 位二进制 `10110110` 在纸上画成 4 个 2-bit 格子，手算第一轮 `v − (v>>1)`，验证每格变成 popcount——这是整个算法的种子；
2. **推导常数**：自己想 0x5555、0x3333、0x0F0F 为什么是"隔一位取一个"的掩码，而不是死记；
3. **推乘法收尾**：写出 `A × 0x01010101` 的展开式，理解"字节值 ≤ 8 时高位窗口内不产生失真进位"（昨天那张预算表的前提）；
4. **推广阅读**：把 bithacks 页刷一遍，重点看 *Compute log2*、*Isolate the rightmost 1-bit*、*Gray code*，感受同一套"字段+掩码+移位"语言；
5. **做题巩固**：LeetCode 191（位 1 的个数）、338（比特位计数）、136（只出现一次的数）；
6. **回到题目**：先写 8 轮纯 SWAR 版本（24 步，超预算），再自己推"哪几层能用乘法折叠"凑进 16 步——推完这一步，这类题对你就是套路而不是谜题了。

核心心法一句话：**把"循环遍历每个 bit"翻译成"一次指令操作所有 bit"，代价就是要不断用掩码维护字段边界**——SWAR 所有技巧都是这一句话的展开。
