## O，CRC循环冗余校验

多用于数据通信中供接收方验证接收到的数据完整性，它不能纠正错误，只能检测错误。假设接收方接收到01数据流，使用CRC-8（4bits表一个数字，8进制）循环冗余校验，去多项式最高项的次数（也就是也就是**除数的位数-1**）n,在数据流末尾加n个0，对其最高有效位进行XOR运算，得到数字即为**CRC校验和**，将其添加到数据串末尾即可。

## ej.

找到我们刚才的例子：

计算`0x1C`的CRC-8的校验结果：
数据串：`0001 1100`
多项式：$x^8 + x^2 + x + 1$

此时我们就可以得到：

数据串（被除数）：`0001 1100 0000 0000`
多项式（除数）：`1 0000 0111`
校验和：　　　　`0101 0100`

这里我们在使用过程中想要发送带有CRC校验的数据，即将校验和添加到原始的数据串后面即可：

数据串：`0001 1100`
校验和：`0101 0100`
带有CRC校验的数据：`0001 1100 0101 0100`

**O,基础概念**

1、域
一组元素的集合，以及在集合上的四则运算，构成一个域。其中加法和乘法必须满足交换、结合和分配的规律。加法和乘法具有封闭性，即加法和乘法结果仍然是域中的元素。  
域中必须有加法单位元和乘法单位元，且每一个元素都有对应的加法逆元和乘法逆元。但不要求域中的 0有乘法逆元。  
2、有限域
仅含有限多个元素的域。因为它由伽罗华所发现，因而又称为伽罗华域。
所以当我们说伽罗华域的时候，就是指有限域。

GF（2^w）表示含有2^w个元素的有限域。
3、单位元
Identity Element，也叫幺元（么元），通常使用e来表示单位元。单位元和其他元素结合时，并不会改变那些元素。
对于二元运算*，若a*e=a，e称为右单位元；若e*a=a，e称为左单位元，若a*e=e*a=a，则e称为单位元。
4、逆元
对于二元运算*，若a*b=e，则a称为b的左逆元素，b称为a的右逆元素。若a*b=b*a=e，则称a为b的逆元，b为a的逆元。
5、本原多项式
域中不可约多项式是不能够进行因子分解的多项式， 本原多项式 （primitive polynomial）是一种特殊的不可约多项式。当一个域上的本原多项式确定了，这个域上的运算也就确定了。本原多项式一般通过查表可得，同一个域往往有多个本原多项式。
通过将域中的元素化为多项式形式，可以将域上的乘法运算转化为普通的多项式乘法再模本原多项式。

> 本原多项式不可约：设 F 是一个域（如有理数域 \(\mathbb{Q}\)、实数域 \(\mathbb{R}\)、有限域 \(\text{GF}(p)\)），多项式 \(f(x)\) 的系数全部属于 F，且次数 \(\deg f \ge 1\)。
> 若 \(f(x)\) **无法**分解为两个次数都严格小于 \(\deg f\)、系数同样在 F 中的多项式的乘积，则称 \(f(x)\) **在域 F 上不可约**；反之称为可约。

1，**多项式运算**

> 域上的运算就是基于多项式运算的

1、多项式加减法（逆运算同理 ，乘法逆元--除法）
将两个多项式中相同阶数的项系数相加或相减。
例如 (x^2 + x ) + (x + 1) = x^2 + 2x +1
2、多项式乘法
将其中一个多项式的各项分别与另一个多项式的各项相乘，然后把相同指数的项的系数相加。
例如 (x^2 + x) * (x + 1) = x^2 * (x + 1) + x * (x + 1） = x^3 + x^2 + x^2 + x
3、多项式除法
使用长除法。例如计算x^3-12x^2-42，除以x-3。使用长除法计算，商x^2-9x-27，余数-123。

3、GF（2^w）上的多项式运算
对于GF（2^w）上的多项式计算，多项式系数只能取 0或1。（如果是GF(3^w)，那么系数可以取 0、 1、 2）
**GF（2^w）的多项式加法中，合并阶数相同的同类项时，由于0+0=0,1+1=0,0+1=1+0=1，因此系数不是进行加法操作，而是进行异或操作。**（本质上是XOR运算）
GF（2^w）的多项式减法等于加法，例如x ^4 – x^4就等于x^4 + x^4。
**3，伽罗华域**

1，GF(p)

有限域GF(p)，其中p为素数。GF(p)里面的加法和乘法与一般的加法和乘法差不多，区别是结果需要mod p，以保证结果都是域中的元素。GF(p)的加法和乘法单位元分别是 0和1。

2，有限域GF(2^w)

GF(p)中p必须是一个素数，才能保证集合中的所有元素都有加法和乘法逆元(0除外)。但实际应用中，很多场合需要 0到255这256个数字能组成一个域。但256不是素数，小于256的最大素数为251，如果直接把大于等于251的数截断为250，则会丢失一部分数据。
因此引入了GF(p^w)，其中p为素数，通常取p=2。计算机领域中经常使用的是GF(2^8)，8刚好是一个字节的比特数。为了保证单位元性质，GF(2^w)上的加法运算和乘法运算，不再使用一般的加法和乘法，而是使用多项式运算。


**4，本原多项式**

伽罗华域的元素可以通过该域上的本原多项式生成。通过本原多项式得到的域，其加法单位元都是 0，乘法单位元是1。
以GF(2^3)为例，指数小于3的多项式共8个： 0， 1， x， x+1， x^2， x^2+1， x^2 + x， x^2+x+1。其系数刚好就是000,001, 010, 011, 100, 101, 110, 111，是0 到7这8个数的二进制形式。
GF(2^3)上有不只一个本原多项式，选一个本原多项式x^3+x+1，这8个多项式进行四则运算后 mod (x^3+x+1)的结果都是8个之中的某一个。因此这8个多项式构成一个有限域。
对于GF(2^3)，取素多项式为x^3 + x+1，那么多项式x^2+x的乘法逆元就是x+1。系数对应的二进制分别为110和011。此时，我们就认为对应的十进制数6和3互为逆元。
部分 GF（2^w）域经常使用的本原多项式如下：
$$
\begin{aligned}
w &= 4: & x^4 + x + 1 \\
w &= 8: & x^8 + x^4 + x^3 + x^2 + 1 \\
w &= 16: & x^{16} + x^{12} + x^3 + x + 1 \\
w &= 32: & x^{32} + x^{22} + x^2 + x + 1 \\
w &= 64: & x^{64} + x^4 + x^3 + x + 1
\end{aligned}
$$

通过本原多项式生成元素
设P(x)是GF（2^w）上的某一个本原多项式，GF（2^w）的元素产生步骤是： 
1、给定一个初始集合，包含0,1和元素x，即 {0,1,x}； 
2、将这个集合中的最后一个元素，即x，乘以x，如果结果的度大于等于w，则将结果mod P(x)后加入集合；
3、直到集合有2^w个元素，此时最后一个元素乘以x再mod P(x)的值等于1。
例如，GF(2^4)含有16个元素，本原多项式为P(x)=x^4+x+1，除了 0、1外，另外14个符号均由本原多项式生成。
注意到x^14=x^3+1，此时计算x^15=x^14*x=(x^3+1)*x=x^4+x=1，生成结束。
**5，伽罗华域上的简化计算**

加法和减法：
加法和减法就是多项式计算中说的异或运算。
乘法和除法：
伽罗华域上的多项式乘法，其结果需要mod P(x)，可以通过以下方式简化计算。

首先，考虑x^8，x^8 mod P(x) = P(x) – x^8 = x^4 + x^3 +x^2 +1 。

对于一般形式的多项式f(x)=a7*x^7 + a6*x^6 + a5*x^5 + a4*x^4 + a3*x^3 + a2*x^2 + a1*x + a0，乘以x得到
x*f(x) = (a7*x^8 + a6*x^7 + a5*x^6 + a4*x^5 + a3*x^4 + a2*x^3 + a1*x^1 + a0*x) mod P(x)
这时有两种情况：
1）a7 == 0，此时结果是一个小于指数小于8的多项式，不需要取模计算。
2）a7 == 1，则将x^8替换为x^4 + x^3 + x^2 +1，而不用进行除法取模计算，结果为：
x*f(x) = (x^4 + x^3 + x^2 +1) + a6*x^7 + a5*x^6 + a4*x^5 + a3*x^4 + a2*x^3 + a1*x^1 + a0*x 
虽然可以通过替换减少除法计算，但还是过于复杂。尤其是在需要大量运算的场合，比如图像处理。于是牛人提出通过查表来减少计算。

## LSFR的行为

这个域为有限域，将其视为多项式运算，则有限性得到解释——即本质上是伽罗华域上的除法运算。

### "抽头"是什么意思

"抽头"（tap）是直译，字面意思是"从某根线上引一根分线出来"。在 LFSR 里，就是**从某些寄存器的输出引一条线，送回输入端参与异或反馈**。

### 抽头多项式怎么读

对照你图里的电路，3 个触发器 FF0、FF1、FF2，反馈线上标了 4 个系数：

```
系数:   1    0    1    1
对应:  x⁰   x¹   x²   x³
```

**系数为 1 → 这一级有抽头（参与反馈异或）；系数为 0 → 没有抽头（直接通过）**。

所以电路结构是：
- x⁰ 系数 1：反馈信号进入第一级 FF0
- x¹ 系数 0：FF0 和 FF1 之间**没有**异或门（图里那个位置没有反馈注入）
- x² 系数 1：FF1 输出处有异或门，反馈注入
- x³ 系数 1：最高位 FF2 的输出就是反馈源

把这些系数拼起来就是抽头多项式：

$$G(x) = 1\cdot x^3 + 1\cdot x^2 + 0\cdot x^1 + 1\cdot x^0 = x^3 + x^2 + 1$$

### 为什么要写成多项式

不只是记法好看，它有真实的代数意义——**LFSR 的整个行为等价于 GF(2) 域上的多项式除法**（就是你图里下面的公式）：

$$R(x) = \frac{M(x)}{G(x)}$$

- $M(x)$：输入数据多项式
- $G(x)$：抽头多项式（除数）
- $R(x)$：寄存器里剩下的值（**余数**）

每来一个时钟，电路做的事就是"多项式模 $G(x)$ 运算"。这正是 **CRC 校验**的原理——CRC 码就是数据多项式除以抽头多项式得到的余数。

### 抽头多项式决定什么

选不同的 $G(x)$，LFSR 的输出序列性质完全不同：

- **是不是本原多项式**：若是，n 级 LFSR 输出周期达到最大 $2^n - 1$（m 序列），**伪随机性最好**；若选得不好，周期很短，序列很快重复
- 应用于：CRC 校验（如 CRC-32 的 $G(x)$ 是国际标准定死的）、伪随机数生成、扩频通信、流密码、扰码器

一句话总结：**抽头多项式就是 LFSR 的"接线图"的代数表达——系数 1 的位置有异或反馈，0 的位置没有；同时它也是 CRC 除法里的除数，决定了输出序列的周期和随机性。**



## 第一步：把寄存器状态看成多项式

3 个触发器的值 (ff2 ff1 ff0)，每一位当作多项式的一项系数：

```
状态 001  →  1·x⁰ + 0·x¹ + 0·x²  =  1
状态 010  →  x
状态 100  →  x²
```

为什么可以这么做？因为**移位这个物理动作，恰好就是"乘以 x"**——每来一个时钟，所有位往高位挪一格，对应多项式每一项的次数 +1。

## 第二步：GF(2³) 的运算规则

GF(2³) 这个域里只有 **8 个元素**：所有次数小于 3、系数为 0 或 1 的多项式（0, 1, x, x+1, x², x²+1, x²+x, x²+x+1）。

两条规则就够：

- **加减法 = 异或**：系数对应位 XOR，没有进位、没有借位。所以 $x^2 + x^2 = 0$，加法和减法是同一回事
- **乘法溢出的部分要对 G(x) 取模**：一旦结果次数 ≥ 3，就用 $G(x)$ 消掉——这就是"模二除法"

## 第三步：为什么 LFSR = 模二除法

关键观察：**x³ mod G(x) 的结果，恰好由抽头决定**。

$$G(x) = x^3 + x^2 + 1 \;\Rightarrow\; x^3 = G(x) + (x^2 + 1) \;\Rightarrow\; x^3 \equiv x^2 + 1 \pmod{G(x)}$$

（注意模二意义下 $-1 = +1$，所以 $x^3 + x^2 + 1 = 0$ 移项得到 $x^3 = x^2 + 1$）

而电路里反馈系数 g₃=1、g₂=1 的物理含义正是：**最高位溢出时，往 x² 和 x⁰ 的位置异或一个 1**——和上面代数消元是同一个动作。所以：

> **一个时钟周期 = 状态多项式乘以 x，再对 G(x) 取余**
> $$\text{下一状态} = x \cdot M(x) \bmod G(x)$$

这就是 $R(x) = \dfrac{M(x)}{G(x)}$（的余数）的含义。

## 第四步：手算验证文章里那张表

| M(x)       | 计算过程                           | R(x)              |
| ---------- | ---------------------------------- | ----------------- |
| x⁰, x¹, x² | 次数 < 3，不用除                   | 就是它自己        |
| x³         | x³ ≡ x²+1                          | x²+1              |
| x⁴         | x·x³ ≡ x(x²+1) = x³+x ≡ (x²+1)+x   | x²+x+1            |
| x⁵         | x·(x²+x+1) = x³+x²+x ≡ (x²+1)+x²+x | x+1               |
| x⁶         | x·(x+1)                            | x²+x              |
| x⁷         | x·(x²+x) = x³+x² ≡ (x²+1)+x² = 1   | x⁰ ← **回到起点** |

每一行就是前一个状态**推进一个时钟**的结果，和文章上面状态图 001→010→100→101→111→011→110→001 完全对应。

## 为什么周期恰好是 7（本原多项式的意义）

- GF(2³) 里非零元素共 $2^3 - 1 = 7$ 个，它们在乘法下构成一个循环群
- 当 $G(x)$ 是**本原多项式**时，$x$ 恰好是这个群的生成元——$x^0, x^1, \dots, x^6$ mod G(x) 遍历全部 7 个非零元素才回到 1
- 所以 LFSR 跑遍全部 7 个非零状态才循环，达到理论最大周期

如果 $G(x)$ 不是本原多项式（比如可以因式分解的），$x$ 的阶就小于 7，LFSR 会在少数几个状态里打转——这就是为什么那张抽头配置表里的多项式必须都是本原多项式。

**一句话总结**：LFSR 每个时钟做的数学操作是"乘 x 再模 G(x)"，状态序列就是 $x^k \bmod G(x)$ 的枚举；G(x) 是本原多项式时，这个枚举恰好扫遍 GF(2ⁿ) 的全部非零元素，周期达到 $2^n - 1$。

## O，前置

### O,流密码

流密码算法通常由异或运算、 与运算以及循环移位等基础操作组成， 这使得流密码算法具有加解密速度快， 软硬件实现简单等特点， 因此常被用于资源受限制的环境条件， 比如处理器性能较弱、 硬件资源有限。

对于流密码而言， 关键在于设计好的伪随机数生成器。一般来说， 密钥 流发生器生成的序列随机性越强， 其明文中的统计特征就会被覆盖的更好。 密钥流发生器的基本构造模块为反馈移位寄存器， 其主要包含线性反馈移位寄存器和非线性反馈移位寄存器。


### 1，基于LFSR的流密码

## 2.2 基于LFSR的流密码
模仿一次一密加密过程，利用有限的key，生成无限的keystream密钥流：
$$k_0,k_1,\dots$$
密码学的攻击模型中，有一种叫做已知明文攻击。也就是，攻击者已知明密文对：
$$(p_1,c_1),(p_2,c_2),\dots,(p_m,c_m)$$
这个过程就是简单的异或运算，所以可得：
$$k_1 = p_1 \oplus c_1,\,k_2 = p_2 \oplus c_2,\dots,\,k_m = p_m \oplus c_m$$

此时便出现了两种解密方法。

**方法一：**
$$\text{从}k_1,k_2,\dots,k_m\text{中恢复初始密钥}$$

**方法二：**
从$k_1,k_2,\dots,k_m$中恢复某一时刻的中间状态$(s_0,s_1,\dots,s_{L-1})$。有了$(s_0,s_1,\dots,s_{L-1})$可以得到同样的密钥流。

结论：只通过LFSR生成密钥流是不安全的。Berlekamp-Massy算法可以利用$2L$长的输出序列，以$O(L^3)$的复杂度得到生成这个序列的线性反馈移位寄存器。
