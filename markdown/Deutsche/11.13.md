## 不规则动词现在时变位

规则动词：只变尾巴 词干+人称代词

不规则动词：词干元音会变（变音或者换音），尾巴还照常变

核心特点：du/er/sie/es这两个人称不变，元音会变；wir/ihr/sie往往不会变

| ---- | ----- |
| ich  | lese  |
|      | liest |
|      | liest |
|      |       |
|      |       |

### 三个换音动词（直陈式现在时 Präsens）

> 规律：a/e → ä/ie，只在 **du / er,sie,es** 单数变位换音；wir / ihr / sie,Sie 和原形一致

#### helfen 帮助（e → i）

ich helfe 

du hilfst

 er/sie/es hilft

 wir helfen 

ihr helft 

sie / Sie helfen

#### sehen 看见（e → ie）

ich sehe 

du siehst 

er/sie/es 

sieht wir 

sehen ihr 

seht 

sie / Sie sehen

#### schlafen 睡觉（a → ä）

ich schlafe 

du schläfst 

er/sie/es schläft 

wir schlafen 

ihr schlaft

 sie / Sie schlafen

------

### 命令式（du 形式）

helfen → hilf! sehen → sieh! schlafen → schlaf!

💡 小结：

- e→i：helfen, geben
- e→ie：lesen, sehen
- a→ä：schlafen, fahren, tragen
