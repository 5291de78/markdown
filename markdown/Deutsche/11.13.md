# 名词的特点
洋光小语种

1. 首字母大写
2. 有阴阳中性，单复数之分

Beispiele:
1. der Herr,-en		词性：阳性	der
Herr(m.-en)
2. die Frau,-en     词性：阴性  die
Frau(f.-en)
3. das Kind,-er    中性  da's
Kind(n.-er)
4. der Mann
die Männer

## Artikel--定冠词

|      | m.   | n,   | f.   | Pl   |
| ---- | ---- | ---- | ---- | ---- |
| Nom  | der  | das  | die  | die  |

无论什么词性，复数一律用die表示

德语中所有名词更着词性变：

阳性

阴性

中性

der Mann

die Frau

der Kind

der Lehere

die Lehrein

| ---- | ---- | ---- | ---- | ---- |

## 德语规则动词变位（6个人称词尾）
1. ich → 词干 + -e
2. du → 词干 + -st
3. er / sie / es → 词干 + -t
4. wir → 词干 + -en
5. ihr → 词干 + -t
6. sie / Sie → 词干 + -en

| 人称代词 | machen |
| ---- | ---- |
| ich | mache |
| du | machst |
| er/sie/es | macht |
| wir | machen |
| ihr | macht |
| sie/Sie | machen |
