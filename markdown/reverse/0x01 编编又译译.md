# **我的回答：**

**高级语言与汇编语言**

高级语言 是接近人类语言和数学表达的编程语言，如 C、Python、Java。

```c++
area = 3.14 * r * r ///人类只需要操控数据进行循环，判断，运算即可
```

我认为高级语言的本质对于人类而言是一套助记符,方便操作与学习，对于机器是一套密码本，编译时期对照指令集将其转译为纯粹的可执行的机器语言指令集合，人类不需要在乎芯片是什么指令集架构的，因此具有很强的移植性

汇编语言介于机器码与高级语言之间，可读性没有高级语言高，但是助记符的存在又让他比纯粹使用0100101的机器码更高级。他直接对cpu，寄存器，I/O设备的数据流进行操作。

**编译型和解释型**

编译型，全部翻译好了机器再执行指令

解释型，一边运行一边编译。。。

**编译的六个阶段**（这个问的d33p533k)

1. 词法分析（Lexical Analysis） **
   - 源代码： int x = 42;
     拆分成： [关键字 int] [标识符 x] [运算符 =] [整数 42] [分号 ;]
   - 扫描源代码字符流，按规则切分成一个个 Token

2. 语法分析（Syntax Analysis）

   - 把 Token 序列按语法规则组织成 **抽象语法树（AST）** 。

   - 检查代码结构是否合法，比如括号是否匹配、语句是否完整。

   - "x = 42;" 的 AST：

       AssignmentStatement
       ├── **type: int**
       ├── **name: x**
       └── **value: IntegerLiteral(42)**

  **3.语义分析（Semantic Analysis）**

- ​	AST 结构正确 ≠ 语义正确。这一阶段检查 类型是否匹配、变量是否已声明、作用域是否合法 。

- int x = 42;       // int = int  ✓
  int y = "hello";  // int = string  ✗ 类型错误！
  int z;            // z 未赋值就使用  ✗ 

  **4.生成中间代码**(IR Generation）

  把 AST翻译成 平台无关的中间表示 （Intermediate Representation）。最著名的是 LLVM IR。这样做的好处：编译器前端只需对接一种 IR，后端只需把 IR 翻译成各种 CPU 的机器码。

  **5.优化（Optimization**）

  IR 上做各种性能优化，这是现代编译器最复杂的部分：

  - 常量折叠 ：`x = 1 + 2` → 直接算成`x = 3`  --+ constexpr???

  - 死代码消除 ：删掉永远不会执行的代码

  - 循环优化 ：把循环不变量提到循环外

  - 函数内联 ：把小函数直接展开到调用处

  - 公共子表达式消除 ：`a = b*c; d = b*c` → 只算一次

    **6目标代码生成（Code Generation）**

把优化后的 IR 翻译成 特定 CPU 架构的机器码 。涉及寄存器分配、指令选择、内存布局
