# 指针
# C/C++ 指针完整写法指南

指针本质是**存储内存地址的变量**，其类型决定了对指向内存的解读方式。下面从基础语法到高频场景，逐一说明标准写法与避坑要点。

## 一、基础定义与初始化

### 语法格式

```c
数据类型 *指针变量名;
```

- `数据类型`：指针指向的内存中存储的数据类型
- `*`：仅在声明时起标识作用，标记该变量为指针类型
- 用 `&变量名` 可获取变量的内存地址，用于给指针赋值

### 标准写法示例

```c
int num = 100;
int *p;       // 先声明int型指针变量
p = #       // 再赋值为num的内存地址

// 声明同时初始化（推荐写法，避免野指针）
int *p = #
```

### 易错提醒：星号的归属

`*` 只与**紧邻的一个变量**绑定，一行声明多个指针时必须逐个加`*`：

```c
int *p1, p2;   // 错误：p1是int指针，p2只是普通int变量
int *p1, *p2;  // 正确：两个都是int型指针
```

## 二、解引用（通过指针读写内存）

解引用语法为 `*指针变量名`，代表**指针指向的内存空间本身**，可直接读取或修改对应内存的值。

```c
int num = 10;
int *p = #

// 读取：*p 完全等价于 num
printf("%d", *p);  // 输出 10

// 修改：直接修改指向内存的值，原变量同步变化
*p = 20;
printf("%d", num); // 输出 20
```

> 快速区分两个场景的`*`：
>
> - 声明时的 `*`：类型标识，说明变量是指针
> - 使用时的 `*`：解引用操作，访问指向的内存

## 三、特殊指针写法

### 1. 空指针

不指向任何有效内存的指针，用于初始化和判空，避免野指针风险。

```c
// C 语言标准写法
int *p = NULL;

// C++ 推荐写法（类型安全性更高）
int *p = nullptr;
```

⚠️ 绝对禁止对空指针进行解引用操作，会直接导致程序崩溃。

### 2. 通用指针 void*

可以接收任意类型的地址，但不能直接解引用，必须强制类型转换后使用。

```c
int num = 10;
void *p = #  // 可接收任意类型的地址

// 使用前必须强转为对应类型
printf("%d", *(int*)p);
```

## 四、指针与数组

数组名本质是数组首元素的地址，可直接赋值给同类型指针。

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;  // 等价于 int *p = &arr[0];
```

通过指针偏移访问数组元素（指针 + 1 会跳过一个对应类型的字节数）：

```c
printf("%d", *p);      // 等价 arr[0]，输出 1
printf("%d", *(p+1));  // 等价 arr[1]，输出 2
printf("%d", *(p+2));  // 等价 arr[2]，输出 3
```

## 五、指针作为函数参数（传址调用）

这是指针最核心的应用场景，用于在函数内部修改外部变量的值。 以 “交换两个整数” 为例：

```c
// 传址交换函数
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 10, y = 20;
    swap(&x, &y);  // 传入变量的地址
    // 执行后 x=20, y=10
    return 0;
}
```

## 六、二级指针（指向指针的指针）

存储一级指针变量的地址，用两个`*`声明。

```c
int num = 10;
int *p = #
int **pp = &p;  // 二级指针，存储一级指针p的地址

// 解引用
printf("%d", *pp);   // 一级解引用，得到p的值（num的地址）
printf("%d", **pp);  // 二级解引用，得到num的值 10
```

## 七、常见错误写法避坑

1. 野指针

   ：未初始化就使用的指针，指向随机内存，会导致不可预期的崩溃。 

   ```c
   int *p;
   *p = 10;  // 严重错误：p未初始化，指向未知内存
   ```

2. 类型不匹配

   ：指针类型必须和指向的变量类型严格一致。 

   ```c
   char c = 'a';
   int *p = &c;  // 错误：int指针不能指向char变量
   ```

3. 返回局部变量地址

   ：函数结束后局部变量会被销毁，地址立即失效。 

   ```c
   int* test() {
       int a = 10;
       return &a;  // 错误：a是局部变量，函数结束后内存被释放
   }
   ```

## 八、其他指针

## i,字符指针

1.  基础定义与两种用法

   ```c
   // 写法1：指向字符串常量（只读，推荐加const）
   const char *str = "hello world"; 
   // str存储字符串首字符'h'的地址，字符串存放在只读常量区
   // 错误操作：*str = 'H'; 修改只读内存会直接触发运行错误
   
   // 写法2：指向字符数组（可读写）
   char arr[] = "hello";
   char *p = arr;
   *p = 'H'; // 合法，修改后数组变为 "Hello"
   
   ```

   2. 典型用法：遍历字符串

   ```c
   // 简易实现字符串长度计算
   int str_len(const char *s) {
       int len = 0;
       while (*s != '\0') { // 遇到字符串结束符停止
           len++;
           s++; // 指针向后移动一个字符
       }
       return len;
   }
   ```

## ii,指针数组

> 存储指针的数组 ， **语法**：`类型 *数组名[数组长度];`

```c
// 示例：存储3个字符串的指针数组
char *fruits[3] = {"apple", "banana", "orange"};

// 访问：fruits[0] 是第一个元素，本身就是char*字符串
printf("%s", fruits[0]);   // 输出 apple
printf("%c", *fruits[1]);  // 输出 b

```

## iii,数组指针

> 指向整个数组的指针 ， **语法**：`类型 (*指针名)[数组长度];`

```c
int arr[2][3] = {{1,2,3}, {4,5,6}};
// p是指针，指向一个长度为3的int数组
int (*p)[3] = arr; 
// 二维数组名arr等价于首行地址，类型刚好是 int(*)[3]
```

## IV函数指针

> 函数指针存储函数的入口地址，通过指针可以间接调用函数，常用于实现回调函数、多态逻辑

### 1. 基础定义与调用

**语法**：`返回值类型 (*指针名)(参数类型列表);`

```c
// 先定义两个普通函数
int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

// 定义函数指针p，指向「返回int、两个int参数」的函数
int (*p)(int, int);

// 赋值：函数名本身就是地址
p = add;
// 调用：两种写法完全等价
int res1 = p(10, 20);     // 简化写法，推荐
int res2 = (*p)(10, 20);  // 完整解引用写法

```

###  2，typedef 简化类型（工程必备）

函数指针类型冗长，用`typedef`重命名后可读性大幅提升

```c
// 把 int(*)(int,int) 这个类型重命名为 CalcFunc
typedef int (*CalcFunc)(int, int);

// 直接用别名定义变量
CalcFunc func1 = add;
CalcFunc func2 = sub;
```

### 3. 典型用法：回调函数

把函数作为参数传入另一个函数，实现灵活的逻辑注入，标准库`qsort`的比较函数就是典型应用：

```c
// 通用计算函数，第三个参数是函数指针（运算规则）
void calculate(int a, int b, CalcFunc op) {
    printf("计算结果：%d\n", op(a, b));
}

int main() {
    calculate(10, 5, add); // 传入加法规则 → 输出15
    calculate(10, 5, sub); // 传入减法规则 → 输出5
    return 0;
}
```
