# PYTHNO列表初始化方法



## 1. 字面量（最常用）

```
# 空列表
lst = []

# 直接放元素
lst = [1, 2, 3, "abc", True]
```

## 2. list() 构造器

```
lst = list()   # 空列表，等价 []

# 把可迭代对象转成 list
lst1 = list((1,2,3))       # 元组转 [1,2,3]
lst2 = list("hello")       # 字符串转 ['h','e','l','l','o']
lst3 = list(range(5))      # [0,1,2,3,4]
```

## 3. 快速生成重复元素（⚠️大坑）

```
# 方式A：[x] * n
a = [0] * 5          # [0,0,0,0,0]
b = [None] * 3       # [None, None, None]

# ❗危险：元素是可变对象（列表、字典）时不要这么写！
bad = [ [0] ] * 3
bad[0][0] = 99
print(bad)   # [[99], [99], [99]] 三个是同一个子列表引用！
```

✅ 正确生成嵌套列表：用列表推导式

```
good = [ [0] for _ in range(3) ]
good[0][0] = 99
print(good) # [[99], [0], [0]]
```

## 4. 列表推导式 list comprehension（最强）

```
# 普通
lst = [i for i in range(10)]        # [0,1,...,9]

# 带条件
lst = [i for i in range(10) if i % 2 == 0] # 偶数

# 双层循环（二维）
mat = [ [0 for _ in range(2)] for _ in range(2) ]
# 得到 [[0,0],[0,0]]，适合你之前模矩阵场景！
```

## 5. itertools 相关（不叫初始化，按需生成）

```
import itertools
lst = list(itertools.repeat(1, 4))  # [1,1,1,1]
```

## 6. 从其他容器转换

```
s = {1,2,3}
lst = list(s) # 集合转列表（无序）
```

# 对比速记

| 写法            | 适合场景                                 | 注意点             |
| --------------- | ---------------------------------------- | ------------------ |
| `[]`            | 空列表、少量已知元素                     | 最简单             |
| `list()`        | 空列表、可迭代对象转列表                 | 不能直接填多个参数 |
| `[val]*n`       | **不可变元素**重复（数字、None、字符串） | 可变对象会引用共享 |
| `[... for ...]` | 复杂规则、二维列表、过滤元素             | 推荐优先用         |
