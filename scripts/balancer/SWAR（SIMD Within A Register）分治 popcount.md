#  SWAR（SIMD Within A Register）分治 popcount

这段代码是经典的 **SWAR（SIMD Within A Register）分治 popcount**：先把 1 的个数逐步折叠到 2 位、4 位、8 位字段，再用**一次乘法**把 32 个字节的计数汇总到顶字节。

先看宽度：`M1/M2` 是 64 个十六进制字符、`M8/K8` 是 32 个字节对，都是 **256 位**；所以 A 是 256 位寄存器，共 32 个字节槽，最后 `>>248` 正是取 256 位的最高 8 位。

## 第一阶段：每个 2 位字段存自己的 popcount（3 步）

```c
B = A >> 1;
B = B & M1;     // 取每个 2 位字段的高位
A = A - B;
```

对任意一个 2 位字段，值 `v ∈ {0,1,2,3}`，结果是 `v - (v>>1)`：

| 原字段 | v    | v−(v>>1) | 含义   |
| ------ | ---- | -------- | ------ |
| 00     | 0    | 0        | 0 个 1 |
| 01     | 1    | 1        | 1 个 1 |
| 10     | 2    | 1        | 1 个 1 |
| 11     | 3    | 2        | 2 个 1 |

于是每个 2 位字段变成了“我这两位里有几个 1”。这里用**减法**代替教科书式的 `(A&M1) + ((A>>1)&M1)`，省掉一次按位与，而且 `v ≥ v>>1`，字段内不会借位，更不会串到相邻字段。

## 第二阶段：相邻 2 位计数合并成 4 位计数（4 步）

```c
B = A >> 2;
B = B & M2;     // 高那个 2 位字段的计数
A = A & M2;     // 低那个 2 位字段的计数
A = A + B;
```

两个计数各不超过 2，相加不超过 4；4 位字段能表示 0~15，所以**加法不会向相邻字段进位**。现在每个 4 位字段就是原来 4 位里的 1 的个数。

## 第三阶段：合并成字节计数（4 步）

```c
B = A >> 4;
B = B & M8;
A = A & M8;
A = A + B;
```

同理，两个 4 位计数各 ≤4，相加 ≤8，一个字节完全装得下。此时**每个字节的值 = 原字节 popcount（0~8）**。

拿一个字节 `1101 0100` 走一遍：

```text
2 位字段: 11 01 01 00  →  计数 2, 1, 1, 0
4 位字段: 2+1=3, 1+0=1  →  0011 0001
8 位字段: 3+1=4          →  0000 0100
```

## 第四阶段：一次乘法完成 32 字节水平求和（2 步）

```c
A = A * K8;     // K8 = 0x0101...01，32 个字节都是 1
A = A >> 248;
```

设各字节计数为 `b₀…b₃₁`。因为

```text
K8 = Σ 2^(8k)，所以 A*K8 = Σ (A << 8k)
```

相当于把 A 的 32 个移位副本全部相加。观察**顶字节那一列**（第 31 列）：只有 `j+k=31` 的字节积会落在这里，k 取遍 0~31 时，j 恰好也取遍 31~0，因此

```text
顶字节 = b₀ + b₁ + … + b₃₁ = 整个 256 位寄存器的 popcount
```

而更低的列最多只累加 `8×31=248`，不会向顶字节进位，所以顶字节干净地保存总和。最后 `>>248` 把它移到最低 8 位即为答案。

**这步是省步数的关键**：若继续按 16、32、64、128、256 位字段折叠，还要 5 轮、每轮 4 条，共 20 条；乘法只要 2 条。

## 步数核对

| 阶段           | 条数   |
| -------------- | ------ |
| 2 位折叠       | 3      |
| 4 位折叠       | 4      |
| 8 位折叠       | 4      |
| 乘法求和＋取出 | 2      |
| **合计**       | **13** |

所以这段 payload 本身是 **13 条运算**，已经在 16 的预算内；若你的评测环境显示 15，通常是把常量装载等额外指令也计入了。

两个实用提醒：若是 64 位版本，只需把掩码缩短并把 `>>248` 改成 `>>56`；另外这个乘法求和把结果限制在一个字节内，**256 位全 1 时真实答案是 256，顶字节会溢出**，如测试包含这种极端用例需要单独特判。
