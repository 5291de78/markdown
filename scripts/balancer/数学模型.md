## 1. 加密侧的数学模型
一切发生在二元域 GF(2) 上（加法 = XOR，乘法 = AND）。

- 状态空间：V = GF(2)²⁵⁶，seed s₀ ∈ V 是未知向量。
- LFSR 状态转移是 线性映射 L: V → V，第 t 拍状态 s_t = Lᵗ(s₀)。
- 掩码即向量：T₁, T₂, W ∈ V。定义线性泛函 ⟨m, s⟩ = ⊕ᵢ mᵢ·sᵢ（代码里的`parity(m & s)` ）。
- 重量函数 w(s) = Σᵢ Wᵢ·sᵢ ∈ ℤ—— 注意这是普通整数加法，不是域内运算 ，正因为它落在 ℤ 上，后面才能产生非线性。
两路输出（t = 0, 1, …, 287）：

u_t = ⟨T₁, s_t⟩ ⊕ ( C(w_t+1, 2) mod 2 )
v_t = ⟨T₂, s_t⟩ ⊕ ( C(w_t,   2) mod 2 )        w_t = w(s_t)


## 2. U⊕V 之后：二次项的代数抵消
逐比特异或（GF(2) 加法），二次部分单独拿出来：

C(w+1,2) + C(w,2) = w(w+1)/2 + w(w−1)/2 = w²          （整数恒等式）
w² ≡ w  (mod 2)                                        （因为 w(w−1) 恒为偶数）
w mod 2 = ⊕ᵢ Wᵢsᵢ = ⟨W, s⟩                             （整数和的奇偶 = 各位异或）


所以

z_t := u_t ⊕ v_t = ⟨T₁ ⊕ T₂ ⊕ W, s_t⟩ =: ⟨M, s_t⟩


这一步的本质是代数次数坍缩 ：单路输出作为 s 的布尔函数，其代数标准型（ANF）次数为 2（C(w,2) = Σ_{i<j} xᵢxⱼ 是全部二次单项式之和）；两路相加后二次单项式两两抵消，次数从 2 降到 1。密码学上，解 256 元二次方程组是 MQ 问题（NP-hard） ，而解线性方程组是 多项式时间 ——整个攻击的含金量就在这一次异或里。

## 3. 掩码回拉：把时间维折叠进常数
z_t = ⟨M, Lᵗ(s₀)⟩ 是关于 s_t 的方程，但我们要求的是 s₀。取 L 的 伴随映射 L*（对偶），由 ⟨m, L(s)⟩ = ⟨L*(m), s⟩ 定义，迭代得：

z_t = ⟨(L*)ᵗ(M), s₀⟩ =: ⟨m_t, s₀⟩


每个 m_t 都是 已知常向量 （M、TAP 全公开）。L* 的显式公式就是代码里那行：`L*(m) = ((m << 1) & REG) ⊕ (m₂₅₅ · TAP)` ——用 XOR 不用 OR，是因为坐标相加发生在 GF(2) 里，1+1=0。

## 4. 为什么每个字节异或提供 8 个方程

生成器内层循环 8 拍打成一个字节，**先进高位**（`u_byte = (u_byte << 1) | u_bit`），即

```
字节 U_k 的第 j 位 = 时刻 t = 8k + j 的输出比特      j = 0,…,7
```

异或是逐位独立运算，所以 `Z_k = U_k ⊕ V_k` 的第 j 位恰好是 `z_{8k+j}`。而这 8 个比特对应 **8 个不同时刻**，每个时刻的回拉掩码 `m_t = (L*)ᵗ(M)` 都不同——L* 每作用一次就把掩码"左移并按抽头异或"，8 个掩码给出 8 行**互相独立**的系数向量：

```
⟨m_{8k},   s₀⟩ = z_{8k}
⟨m_{8k+1}, s₀⟩ = z_{8k+1}
     ⋮
⟨m_{8k+7}, s₀⟩ = z_{8k+7}
```

所以**一个字节对 = 8 个时刻 = 8 个方程**。36 个字节对 → 288 个方程，未知数 256 个，超定 32 个——既保证秩满（解唯一），又留出冗余做一致性自检（脚本里"全部 288 比特逐一验证"就是消费这 32 个多余方程的信息量）。

## 5. 为什么是高斯消元

经过第 2、3 步，问题已经严格化为 GF(2) 上的线性方程组：

```
A · s₀ = z,   A ∈ GF(2)^{288×256}（第 t 行是 m_t），z ∈ GF(2)^{288}
```

解线性方程组的通用算法就是高斯消元——它在**任何域**上都成立，GF(2) 只是其中一个特例。这个特例带来两个工程红利：

1. **没有数字，只有位**：每个系数是 0/1，一行可以塞进一个 256 位整数，消元中的"行相减"就是一次 XOR（GF(2) 里加=减=异或），一次行操作等价于一条 CPU 指令处理 64 位；
2. **没有除法**：主元只可能是 1，归一化步骤直接消失。

复杂度 O(288 × 256²) 次位运算，现代 CPU 上毫秒级。

对比攻击前后的难度，就能看清整条链路的逻辑：

| 阶段                  | 方程形式                    | 求解难度                   |
| --------------------- | --------------------------- | -------------------------- |
| 攻击前（单看 U 或 V） | 256 元二次方程组（MQ 问题） | NP-hard，指数级            |
| U⊕V 之后              | 256 元线性方程组            | 高斯消元，多项式级（毫秒） |

**总结**：U⊕V 把二次滤波器打回线性（次数 2→1），掩码回拉把"关于第 t 拍状态的方程"统一改写成"关于 seed 的方程"，每个字节提供 8 个时刻的观测即 8 行系数，288×256 的 GF(2) 矩阵用高斯消元一次解出——攻击完成。
