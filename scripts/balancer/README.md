## 怀旧之秤——司天监的遗忘之秤

> 星槎坠海的第三百年，司天监最后一任「掌秤人」在陨星渊底封存了整座文明的记忆——一枚 256 位的忆晶，悬上**怀旧之秤**的秤盘。此秤不称金铁，不称生死，只称**记忆之重**。

### 连接方式

正式环境请使用题目页面显示的 `nc <host> <port>` 连接服务。

服务首先要求提交 **Stage 0 校权程序**：一行以 `;` 结尾、总长不超过 2500 的
赋值序列，每条形如 `X=Y op Z`（`X`、`Y` ∈ {`A`, `B`}，`Z` 为 `A`/`B` 或十进制数）。

- 计费：`+ - << >> & ^` 每条 1 步；`* // %` 每条 3 步；总预算 **16 步**；
- 每步执行后 `A`、`B` 都被截断到 256 位；
- 校准目标：对 100 组随机忆晶，程序执行结束后 `A` 必须等于初始 `A` 的
  popcount（二进制中 1 的个数）。

校准通过后，服务一次性输出全部封印数据并断开：

```text
N = ...
e = ...
a_off = 7
shift_bits = ...
c_rsa = ...
hill_ct = [(c0, c1), ...]    # 39 组 2 字节密文对（前 3 组是咒绢头）
```

Flag 即 `c_rsa` 在完整解封后的明文。

### 本地调试

### 提示

- 绢首的六字真言是历代掌秤人特意留下的钥匙孔；
- 星轮滤出的星辉有两路，凡人只盯一路，永远陷在迷雾里；
- `p+q` 的前 256 位星轨，就藏在星轮的种子里。

| 步骤 | 内容 | 步数 |
|---|---|---|
| 折叠到 2 位字段 | `B=A>>1; B=B&M1; A=A-B` | 3 |
| 折叠到 4 位字段 | `B=A>>2; B=B&M2; A=A&M2; A=A+B` | 4 |
| 16 槽并行求和 | `A=A*K` | 3 |
| 结果移到低位 | `A=A>>240` | 1 |
| **合计** | | **11 / 16** ✓ |

常数（用 Python 现算十进制）：M1=int('5'*64,16)、M2=int('3'*64,16)、K=int('0001'*16,16)。

正确性你可以自己推一遍：第一轮后每 2 位字段 ≤2，第二轮后每 4 位字段 ≤4（所以一个 16 位槽 ≤16），乘积的第 240~255 位 = 16 个槽之和 = popcount（≤256 恰好塞进 16 位窗口，无进位丢失）。
这个 server.py 干了什么（按它自己的注释讲）
整体是一条四阶段攻击链，每次连接先过 Stage 0，然后生成一套参数发给你，连接即结束（没有交互轮次）：

Stage 0：SWAR popcount 校准
让你提交一条 ; 分隔的赋值语句序列（只许操作寄存器 A/B 和运算符），有"步数预算"：+ - & ^ << >> 各扣 1 步，* // % 各扣 3 步，总共 ≤16 步。服务器拿 100 个随机 256 位数跑你的语句，要求最终 A 必须等于输入的 popcount（二进制 1 的个数）。考察的是位运算技巧：经典 SWAR 移位-加法树能不用循环在常数条语句内算出 popcount。

会话生成（build_session）：

生成两个 512 位素数 p、q，N = pq，固定 a_off = 7，定义 Ψ = (p−7)(q−7)；

取 340 位的 u，算 e = u⁻¹ mod Ψ——这是"广义 RSA"：逆元是对 (p−a)(q−a) 取的，不是标准的 (p−1)(q−1)；

S = p + q，取 S 的高 256 位当 seed；

FLAG 用 RSA 加密（指数 e，模 N）得 c_rsa；

seed 驱动一个 256 位 LFSR（反馈多项式 x²⁵⁶+x¹⁰+x⁵+x²+1），每个状态用 weightwise quadratic filter（对 W_MASK 选中位做 popcount 得 w，再算 w(w±1)/2 的奇偶）产生 u、v 两个通道的比特，凑成 36 字节双流；

把 "CIPHER" 头 3 个字节对 + 36 组 (U,V) 字节对，用 Z₂₅₆ 上的 2×2 仿射 Hill 密码（矩阵 K 要求行列式为奇即可逆，加偏移 B）加密，输出 hill_ct。

最后它一次性发给你 N、e、a_off、shift_bits、c_rsa、hill_ct 六样东西，连接关闭。注释里自己写了后三阶段的攻击路线（参考论文都列了）：已知明文头差分破 Hill → u⊕v 抵消二次项后对 LFSR 线性化高斯消元恢复 seed → 用 p+q 高位 + 广义 RSA 结构做修正连分数分解 N。
