## 线性孪生——冷钱包的审计模式

御林娘的冷钱包在离线审计模式下，每次会话都会临时生成一把 secp256k1
密钥，并连续为两条审计记录签名。为了在没有硬件随机数的环境里复现签名，
固件使用一条**线性阶梯**来推进 nonce：

```text
k1 <- 随机
k2 <- a * k1 + b  (mod n)
```

阶梯系数 `a`、`b` 由一块 16 位的微调寄存器（trim register）展开得到，具体
展开方式见附件中的 `server.py`。两条审计记录使用不同的消息，但共享同一把
临时私钥。

### 连接方式

正式环境请使用题目页面显示的 `nc <host> <port>` 命令连接服务。

服务会依次输出曲线名、公钥、两条记录的原文/哈希/签名，然后封存私钥并提示：

```text
private_key_hex> 
```

提交该会话临时私钥的十六进制值（可带 `0x` 前缀）即可取回审计凭证。每会话
最多尝试 5 次；失败后重新连接会得到一把全新的密钥。

### 本地调试

附件中的 `server.py` 与容器内的服务相同，可直接在本地运行：

```bash
YL_DYFLAG='YulinSec{local_only}' PORT=20000 python3 server.py
nc 127.0.0.1 20000
```

附件中不包含正式 Flag；容器启动时由平台通过 `YL_DYFLAG` 注入。
