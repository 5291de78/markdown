# XOR异或运算

> 二进制的无进位相加

## 运算规则
1. 交换律：$a \oplus b = b \oplus a$
2. 结合律：$(a \oplus b) \oplus c = a \oplus (b \oplus c)$
3. 自反性：$a \oplus a = 0$
4. 零元：$a \oplus 0 = a$
5. 可逆性：若 $a \oplus b = c$，则 $a = c \oplus b,\; b = c \oplus a$

从这些运算规则其实就可以推到出很多有意思的性质，而这些性质需要长期的积累与自我探索发现

```c++
def swap(a , b):
    a = a + b
    b = a - b
    a -= b
    
void swap(int a , int b){
    a = a^b;
    b = a^b;
    a = a^b;
}
```
